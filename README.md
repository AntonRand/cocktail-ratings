# Cocktail Ratings

A shared rating board for Anton and Verity to score cocktails out of 10.

## Cocktails

- Mojito
- Gin Gin Mule
- Old Fashioned
- Aperol Spritz
- Negroni
- Hugo
- Strawberry Margarita
- Pina Colada
- Mandarin Collins
- The Strawberry Statement
- Dark & Stormy
- Garden of Eden

## Run locally

```bash
npm install
npm start
```

Open http://localhost:3000

Ratings are stored in `data/ratings.db` (SQLite).

## Deploy

Works on any Node.js host with persistent disk (Railway, Render, Fly.io, etc.). Set `PORT` if needed.
